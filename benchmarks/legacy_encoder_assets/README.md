# Historical website assets

These files are retained for research provenance outside the deployed `docs/`
directory. They are not included in the project website.

This is the earlier website's asset set, not a synchronized experiment export:
`metrics.json` came from the May subject fit, while the images and meshes were
later updated in August for the encoder experiment. Use git history to inspect
their original versions. Current reproducible full-label Gaussian results are
documented in [the reference notes](../may2026_gaussian_reference.md).
